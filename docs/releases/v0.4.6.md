## English

- Add light, dark and system themes with saved preferences, consistent status colors and readable controls.
- Add a collapsible sidebar and a dedicated Settings page. Keep device actions available in smaller windows and curve labels readable.
- Keep minimized windows in the taskbar. Make closing to the tray or exiting configurable, and restore controlled fans before exit.
- Protect unapplied edits when closing an editor or exiting. Fix reduced-motion menu positioning and the incorrect restart notice on first connection.

Validated with 40 frontend behavior and contrast tests, Windows core and worker tests, and the native desktop demo. Real window checks used 200% DPI, including a 920×660 window. Physical fan writes, other native DPI settings and cross-monitor scaling remain unverified. The installer is unsigned.

## 简体中文

- 新增浅色、深色与跟随系统，保存显示偏好，统一状态配色与控件对比度。
- 新增可折叠侧栏和独立设置页，窄窗口保留设备操作，曲线刻度保持可读。
- 最小化保留在任务栏，关闭窗口可选择进入托盘或退出，退出前恢复已接管风扇。
- 关闭编辑器或退出时保护未应用的修改，修复减少动效时的菜单定位和首次连接误报重启。

已通过 40 项前端行为与对比度测试、Windows 核心与服务测试及原生桌面演示回归。真实窗口覆盖 200% DPI 和 920×660 最小尺寸。物理风扇写入、其他原生 DPI 和跨屏缩放仍未实测。安装程序尚未代码签名。
