## English

- Match the Cinna installer style with a cream sidebar, FanController artwork, branded page headers and versioned window titles. Apply the same branding to uninstall pages.
- Give component choices the full content width and preserve the existing shortcut and launch options.
- Recognize the current application title and three earlier titles when requesting a normal exit before upgrading. Continue waiting for fan restoration and worker shutdown.

The Windows installer is unsigned. Installation and uninstall checks use isolated files and registry records; physical fan control is not exercised.

## 简体中文

- 安装器统一为 Cinna 向导样式：奶油色侧栏、FanController 图标、品牌页头和带版本的窗口标题，卸载界面同步使用。
- 组件选项使用完整内容宽度，保留现有快捷方式与安装后打开选项。
- 升级时识别当前窗口标题及三种旧标题，请求正常退出后继续等待风扇恢复和服务结束。

Windows 安装包尚未代码签名。安装与卸载使用隔离文件及注册项验证，没有操作真实风扇。
